Author: Dhruv Varshney

Developed a Retrieval-Augmented Generation (RAG) chatbot using Streamlit, FAISS, Hugging Face embeddings, and a local Qwen2.5 Small Language Model (SLM) to answer document-based queries with contextual and accurate responses.

Implemented dynamic PDF upload, semantic retrieval, conversational memory for follow-up questions, and real-time streaming responses, enabling users to interact naturally with uploaded documents.
